# MemoGraph - 智能笔记图谱

## 简介
MemoGraph 是一个结合了双向链接笔记与可视化知识图谱的个人知识管理工具。所有数据存储在浏览器本地，无需注册账号，保护你的隐私。

## 功能特性
- 📝 **Markdown 笔记编辑** - 实时预览，支持完整的 Markdown 语法
- 🔗 **双向链接** - 通过 `[[笔记标题]]` 语法创建笔记间关联
- 🕸️ **知识图谱** - 可视化展示笔记之间的关联网络
- 🔍 **全文搜索** - 快速检索所有笔记内容
- 🏷️ **标签系统** - 按标签组织笔记
- 📂 **自动保存** - 每次编辑自动保存，无需担心数据丢失
- 🌙 **深色模式** - 保护眼睛，夜間使用更舒适
- 📤 **导入导出** - 支持 Markdown 文件导入和 JSON 导出

## 使用方法
直接打开 `index.html` 即可使用。

## 技术架构
- 纯前端应用，无需后端服务
- 使用 IndexedDB 进行本地数据存储
- 使用 Canvas 实现知识图谱可视化
- 使用 marked.js 进行 Markdown 渲染
